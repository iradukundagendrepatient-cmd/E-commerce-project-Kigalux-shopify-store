## Project Description

Kigalux is a functional e-commerce website built to transform our Assignment IV-a Figma UI/UX design into a working, live store. The site brings the same core mission forward: giving local Rwandan tailors and designers a dedicated digital storefront to showcase and sell authentic, locally made clothing to a national and international audience.

The store was built and customized using Shopify's no-code tools — theme customization, page builder, and product catalog — without writing any code, demonstrating how a business idea and a UI/UX design can be turned into a real, working web application.

---

## Features Implemented

* **Homepage** with store name, welcome/introduction message, and a banner layout representing the Made-in-Rwanda tailoring brand.
* **Product Page** featuring 5 products, each with an image, name, price, and description highlighting local craftsmanship.
* **About Page** describing the Kigalux business and its mission of supporting local Rwandan tailors and promoting Made-in-Rwanda fashion nationally and internationally.
* **Contact Page** with a working contact form and a listed email/phone number.
* **Shopping Cart functionality** — products can be added to the cart, with the cart updating and viewable in real time (built-in Shopify checkout flow).

## Challenges Encountered

* Shopify's free trial keeps the store behind a password-protected "Opening soon" page by default, which required clearly documenting the password alongside the live link so it doesn't block access during grading.
* Translating a static Figma design into a fully functional, no-code Shopify theme required adapting some UI elements to fit Shopify's built-in section and template structure.
* Sourcing product descriptions and imagery that authentically represented local Rwandan tailoring and textile art within the platform's product page format.

---

## Lessons Learned

* No-code platforms like Shopify can convert a UI/UX design and business idea into a real, functioning website quickly, without requiring custom code.
* Small platform constraints (like trial password protection) matter for real-world deployment and need to be clearly communicated to end users/reviewers.
* Thoughtful product copywriting and page structure play a big role in communicating a brand's mission — in this case, supporting and promoting local artisans — even within a template-based platform.
